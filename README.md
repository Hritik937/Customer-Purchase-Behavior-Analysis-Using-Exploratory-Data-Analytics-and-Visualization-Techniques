# Customer Purchase Behavior Analysis Using Exploratory Data Analytics and Visualization Techniques

This repository contains a college-ready data analytics project built around a public shopping trends dataset.

## Project objective

The aim of the project is to understand customer purchase behavior using exploratory data analysis, feature engineering, and visual storytelling. The analysis focuses on product popularity, customer demographics, seasonal patterns, estimated customer value, and rule-based segmentation.

## Dataset used

* **Dataset name:** Customer Shopping Trends / Shopping Trends dataset
* **Records:** 3,900 customer-level rows
* **Main fields:** age, gender, item purchased, category, purchase amount, location, season, review rating, subscription status, payment method, frequency of purchases
